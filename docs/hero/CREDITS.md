# Hero image credits

The banner at the top of the README is a composite. Two photographs supply the
outside world; everything else (the person, the window frame, the wind-blown
rain, the colour grade and the type) is drawn by
[`docs/build_hero.py`](../build_hero.py) and rasterised with headless Chrome.

Both photographs are **CC0 1.0** (public domain dedication). No attribution is
legally required; it is given anyway, and the sources are recorded here so the
image can be rebuilt from scratch.

| file | what it is | author | source | licence |
| --- | --- | --- | --- | --- |
| `glass.jpg` | rain on a window with out-of-focus city lights behind it | Mary | [StockSnap.io](https://stocksnap.io/photo/rain-window-UL48EW7VNB) | CC0 1.0 |
| `street.jpg` | a rain-slicked street at night with traffic-light reflections | Mary | [StockSnap.io](https://stocksnap.io/photo/night-city-MIONYWYWGU) | CC0 1.0 |

Changes made to both: cropped, scaled, blurred, colour-graded, blended with each
other, and overlaid with vector art.

The same scene also exists as pure vector artwork with no photographic input, at
[`docs/figures/hero.svg`](../figures/hero.svg), regenerated by
[`docs/make_figures.py`](../make_figures.py). It carries no attribution
requirement at all and is the version to prefer if you fork this repository and
want to avoid third-party content entirely.

Rebuild the composite with:

```bash
python docs/build_hero.py      # needs Chrome or Edge, and Pillow
python docs/make_figures.py    # rebuilds the pure-vector figures
```
